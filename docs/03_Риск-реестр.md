> Минимум пять строк. Типовые риски учебных проектов, начните с них:
>
> - не дадут доступ к данным или их окажется меньше, чем рассчитывали
> - данные окажутся непригодного качества
> - выяснится правовое ограничение на использование материала
> - участник команды выбыл (болезнь, работа, академ)
> - модель не даёт приемлемого качества
> - не хватает вычислительных ресурсов
> - внешний сервис или API перестал работать / стал платным
> - не успеваем к защите
