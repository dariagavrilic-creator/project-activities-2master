- [ ] Данные собраны, лежат в `data/` (локально, не в git)
- [ ] В репозитории есть скрипт или подробное описание того, как их собрать заново
- [ ] Заполнен `docs/06_Данные.md`: источник, объём, лицензия
- [ ] Проверена правовая сторона: данные можно использовать легально
- [ ] Если в данных есть сведения о людях — описаны согласие и анонимизация
- [ ] Данные открываются и читаются: прочитали глазами 10 случайных записей
- [ ] Найдены и записаны минимум три проблемы в данных
- [ ] Если нужна разметка — написана `docs/07_Инструкция_по_разметке.md`
- [ ] Сданы документы фаз 0–2: карточка, аналоги, риск-реестр, ТЗ, бэклог

## Веха 2 — 24 октября. MVP и перекрёстное тестирование

Проверка «это MVP, а не прототип» — три вопроса, на все нужен ответ «да»:

- [ ] Посторонний человек может получить пользу без вашего присутствия
- [ ] Работает на данных, которые вы не подбирали специально
- [ ] Запускается на другом компьютере

Готовность к тестированию:

- [ ] README содержит рабочую инструкцию по установке и запуску
- [ ] `requirements.txt` заполнен с зафиксированными версиями
- [ ] Проект склонирован в чистую папку и запущен с нуля — получилось
- [ ] Все задачи группы Must have из бэклога закрыты
- [ ] В репозитории есть история коммитов за весь период, а не один коммит

**На паре:** живое демо 5 минут + перекрёстное тестирование чужого проекта.
